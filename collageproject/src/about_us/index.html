About Us

Full Stack Project (INT219 & INT220)

This website has been developed as a part of our INT219 and INT220 full stack project by LPU students. The topic of the project is a voice and text-based chatbot application. The frontend is built using HTML, CSS, JavaScript, and jQuery, while the backend is powered by PHP and MySQL. The system also includes an advanced chatbot to enhance user interaction and provide intelligent assistance.
